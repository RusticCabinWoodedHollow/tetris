# Тетрис — дзен-режим

PWA-тетрис в неон-стиле: бесконечный режим, скорость никогда не растёт, без счёта и таймеров — просто складывать.

## Особенности

- Стартовый экран — только «ТЕТРИС» и кнопка «ИГРАТЬ».
- Кнопка «Установить приложение» в шапке (мобайл и десктоп) — PWA работает офлайн.
- Неон-стиль (тёмная navy + циан), светлая тема, звук вкл/выкл.
- Управление: стрелки / WASD, пробел — жёсткий сброс, P — пауза; на тач — свайпы.

## Структура

Один файл `index.html` (сборка React, без исходников в репо) + `icons/`, `manifest.webmanifest`. Деплой — ветка `main` (GitHub Pages).
